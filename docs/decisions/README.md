# Décisions d'architecture

Ce dossier contient la [trame ADR](template.md). Aucune décision d'architecture n'est encore acceptée.

Créer un fichier numéroté uniquement lorsqu'une décision réelle est proposée. États possibles : **Proposed**, **Accepted**, **Rejected**, **Superseded**. Seul **Accepted** indique une décision approuvée. Documenter l'auteur, la date, les alternatives et l'autorité de validation dans l'ADR. Un changement important suit une nouvelle revue ; ne pas transformer une proposition en décision implicite.
