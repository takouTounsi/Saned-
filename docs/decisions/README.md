# Architecture decisions

This directory contains the [ADR template](template.md). No architecture decision has been accepted yet.

Create a numbered file only when there is a real decision proposal. Allowed statuses are **Proposed**, **Accepted**, **Rejected**, and **Superseded**. Only **Accepted** indicates approval. Record the author, date, alternatives, and approval authority in the ADR. Significant changes require another review; a proposal must not become an implicit decision.
