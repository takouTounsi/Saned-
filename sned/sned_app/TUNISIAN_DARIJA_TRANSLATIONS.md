# CIN Scanner — English to Tunisian Darija

This is a proposed translation review sheet for the existing interface. No application text has been changed yet.

The translations use Tunisian Darija in Arabic script, with familiar technical terms such as `QR`, `CIN`, and `OCR` kept where that is clearer for users.

## Notes for review

- `تلفون` is intentionally colloquial and Tunisian-friendly; `هاتف` can be used for a more formal tone.
- `توّا`, `باهي`, `بلاصة`, `نحّي`, and `كمّل` give the interface a clear Tunisian Darija tone.
- `التصاور` is used for user-facing “scans/photos”; `التصويرة` is used for a single image.
- The gender field is translated as `ولد` for `M`, while the existing code currently displays `بن`. Confirm the preferred wording before implementation.
- Arabic punctuation and right-to-left layout should be added during implementation, while technical values such as CIN numbers, dates, QR, OCR, and URLs should remain readable in Latin/numeric direction.
